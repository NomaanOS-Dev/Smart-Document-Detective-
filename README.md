# 🔍 Smart Document Detective

An advanced **AI-powered Retrieval-Augmented Generation (RAG)** application engineered for high-precision technical, legal, and forensic document analysis.

Developed by **[NomaanOS-Dev](https://github.com/NomaanOS-Dev)**.

---

## 🚀 Key Features

* **Rigorous Contextual Retrieval:** Uses vector embeddings to chunk, index, and query lengthy PDF documents without contextual degradation.
* **Evidence Citation Engine:** Returns exact document evidence chunks along with the final AI inference for auditability and verification.
* **Interactive Investigation UI:** Built-in Streamlit interface allowing dynamic user queries and instant findings extraction.
* **Vector Store Integration:** Powered by ChromaDB for fast, low-latency semantic similarity search.

---

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **Orchestration Framework:** LangChain / LangChain Community
* **LLM Engine:** OpenAI `gpt-4o-mini`
* **Vector Database:** ChromaDB
* **UI Framework:** Streamlit
* **PDF Processing:** PyPDF

---

## 📦 Local Setup & Installation

1. **Clone the Repository:**
   ```bash
   git clone [https://github.com/NomaanOS-Dev/Smart-Document-Detective-.git](https://github.com/NomaanOS-Dev/Smart-Document-Detective-.git)
   cd Smart-Document-Detective-
   ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Application:**
   ```bash
   streamlit run app.py
   ```
